# CarrorOS

> *"DeepSeek V4 Flash + CarrorOS 用出了以前 Opus-4.6 的感觉。而 Opus-4.6 贵到没法日常用。"*

DeepSeek V4 Flash 之前只能做简单短任务，做不了长任务。
因为模型有上下文窗口限制，做着做着就偏了，偏了就得人从头来。

CarrorOS 用三件事解决了这个问题：

**任务文档磁盘化 + Token 磁盘化**
任务文档、计划、证据全部写磁盘。compact 不丢，新会话能续接。
DeepSeek 的上下文只装当前这一步，前后文都在磁盘上。

**工作流让每个任务完整闭环**
通过 gate 强制 init → execute → verify → archive。
每步有证据、有验证、有审计。偏了拦回来，没做完不放过去。
不是靠模型的自觉，是工作流在执行层面保证。

**AI 自决策**
AI 不是凭空变聪明。哲学（7 条优先级）、铁律（8 条硬规则）、现状（代码/配置/状态）、ROI（实现成本 vs 收益）——这四层构成了 AI 做判断的依据。
而且它不是写死的。哲学优先级可以调，铁律可以加，现状实时在变，ROI 取决于当前上下文。CarrorOS 随着你的需要改动，是你的分身，用你的价值观去处理事情。
