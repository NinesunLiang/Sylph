# CarrorOS

> *"DeepSeek V4 Flash + CarrorOS 用出了以前 Opus-4.6 的感觉。而 Opus-4.6 贵到没法日常用。"*

DeepSeek V4 Flash 之前只能做简单短任务，做不了长任务。因为模型有上下文窗口限制，做着做着就偏了，偏了就得人从头来。

CarrorOS 用三件事解决了这个问题：

**任务文档磁盘化 + Token 磁盘化** — 任务文档、计划、证据全部写磁盘。compact 不丢，新会话能续接。DeepSeek 的上下文只装当前这一步，前后文都在磁盘上。

**工作流让每个任务完整闭环** — 通过 gate 强制 init → execute → verify → archive。每步有证据、有验证、有审计。偏了拦回来，没做完不放过去。不是靠模型的自觉，是工作流在执行层面保证。

**AI 自决策** — AI 更加聪敏，不是傻傻地等人。用户一句话，AI 自己规划、自己执行、自己验证、自己闭环。CarrorOS 只提供护栏，护栏内模型自由发挥。
