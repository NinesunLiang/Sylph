# Auto-Fix 通用模板

> 通用修复模板（语言无关）。语言专项模板见对应 `rules-{lang}.md` 同目录。
> 每个问题最多 2 次修复尝试。

| 规则 | 修复模板 |
|------|---------|
| 硬编码敏感信息 | 提取到环境变量 / 配置中心 / Secret Manager |
| 缺失错误处理 | 添加 `try/catch` 或 `if err != nil { return }` |
| 日志敏感信息泄漏 | 截断/脱敏敏感字段，改用 `[REDACTED]` |
| 过长函数 | 按职责拆分为 ≤50 行的子函数 |
| 重复代码 | 提取公共函数 / 工具类 / 复用现有组件 |
