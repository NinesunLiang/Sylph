# 通用代码审查规则（语言无关）

> 适用于所有语言。语言专项规则见 `rules-{lang}.md`。

## 硬编码敏感信息（P0）
- 密码/ApiKey/Token 硬编码在代码中
- 内网IP/域名直接写在配置或代码里
- 数据库连接串明文

## 不安全的随机数/加密（P0）
- `Math.random()` 用于安全场景（密码/Token/会话ID）
- 自定义加密算法代替标准库

## 缺失错误处理（P1）
- 外部调用（HTTP/DB/文件/网络）未处理异常
- 错误被 `catch {}` 或 `// ignore` 静默吞掉

## 过长函数/方法（P2）
- 函数超过 200 行
- 函数职责不单一（做了IO/业务/日志混合）

## 重复代码（P2）
- 超过 10 行相似代码块
- 可提取公共函数/工具类

## 注释与代码不一致（P2）
- 过时注释误导
- 明显复制粘贴留错

## 日志敏感信息泄漏（P2）
- 日志输出 Token/密码/完整请求体
- 错误堆栈直接暴露给用户

## 不合理空值处理（P1）
- 函数返回可能为空但调用方未防御
- 连续链式调用无空值保护
